# 1024 大厦

把社区的盖楼帖盖成一座楼。每一条回帖就是一层，楼随回帖实时生长，目标 1024 层。

## 本地运行

需要 Node 18 以上版本，无需安装任何依赖。

```bash
git clone https://github.com/cnddb-2024/tower-1024.git
cd tower-1024
node server.mjs
```

启动后按控制台提示在浏览器打开 http://localhost:8788，端口被占用时会自动换下一个。

## 说明

- 双击 index.html 打开看到的是内置快照，数据不会动。运行上面的命令起本地服务，刷新页面即可实时同步
- 数据来自论坛盖楼帖，服务端缓存 90 秒
- 页面是纯静态文件加一个小接口，克隆即用
